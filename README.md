# 🧠 NeuroLearn - AI Powered Learning Accountability Platform

> **Learn. Reflect. Improve. Every Day.**

NeuroLearn is an AI-powered learning accountability platform that helps students build consistent learning habits through task planning, daily reflections, AI-based evaluation, personalized assessments, streak tracking, and analytics.

Unlike traditional learning management systems that focus only on content delivery, NeuroLearn focuses on **measuring understanding and learning progress** through AI-driven feedback and self-reflection.

---

## 📌 Problem Statement

Many students study regularly but struggle to answer questions such as:

- Am I actually understanding what I learn?
- Am I studying consistently?
- Which topics am I weak in?
- How much have I improved over time?

Most productivity applications only track completed tasks and do not evaluate actual learning outcomes.

NeuroLearn solves this problem by combining **daily planning, reflective learning, AI evaluation, and performance analytics** into a single platform.

## 📖 Daily Learning Journal

At the end of each learning session, users can write a reflection about what they learned.

### Example

> Today I learned about CPU Scheduling algorithms including FCFS, SJF, and Round Robin Scheduling. I also understood context switching and CPU utilization.

### Stored Information

- Date
- Time
- Journal Content
- User ID

This creates a complete learning history for future analysis.

---

## 🤖 AI Learning Evaluation

After submitting a journal entry, AI evaluates the learning reflection.

### AI Analysis Includes

- Understanding Score
- Learning Quality Score
- Key Concepts Identified
- Personalized Feedback
- Areas for Improvement

### Example Output

**Score:** 8.5/10

**Concepts Identified**

- FCFS Scheduling
- Round Robin Scheduling
- Context Switching

**Feedback**

Good understanding of scheduling concepts. Include real-world examples to strengthen conceptual clarity.

---

## 📝 AI Question Generation

Based on the user's journal entry, AI automatically generates assessment questions.

### Question Types

#### Easy

- Recall-based questions

#### Medium

- Concept comparison questions

#### Hard

- Analytical and problem-solving questions

### Example

**Easy**

What is Round Robin Scheduling?

**Medium**

Differentiate FCFS and SJF Scheduling.

**Hard**

Which scheduling algorithm is best for a time-sharing system and why?
